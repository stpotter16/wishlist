# Wishlist

A web app for running an annual adopt-a-family gift drive.

- Admins enter households (a mom and her children, or a single woman) and a wishlist for each member.
- Givers browse unclaimed households and claim one, leaving their name, email, and phone for the admins.
- Each giver gets a private link to come back and review their household's wishlists.

See [AGENTS.md](AGENTS.md) for the full domain model and development commands.
