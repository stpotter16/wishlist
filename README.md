# Wishlist

A web app for running an annual adopt-a-family gift drive.

- Admins enter anonymous families and a wishlist for each family member.
- Givers browse unclaimed families and claim one, leaving their name, email, and phone for the admins.
- Each giver gets a private link to come back and review their family's wishlists.

See [AGENTS.md](AGENTS.md) for the full domain model and development commands.
